# Volcablearn

**用遺忘曲線背雅思單字的閃卡網站。** 免費、免註冊，打開就能用。

👉 **立即使用：https://rjian-collab.github.io/Volcablearn/**

![Volcablearn 預覽](og-image.png)

## 可以做什麼

- **閃卡**：看英文，翻面看中文、例句、同義字和搭配詞，自己按「不會／模糊／會」。
- **自動排複習**：依照遺忘曲線計算每個字什麼時候快忘了，在那天提醒你複習；越熟的字間隔越長。
- **新增自己的單字**：輸入單字，AI 幫你補上詞性、中文、例句、同義字和搭配詞，確認後加入閃卡（AI 需要自己的免費金鑰，沒有金鑰也能手動新增）。
- **測驗**：填字拼寫、選意思、同義字與詞性轉換、例句挖空、易混字辨析（例如 mainly / chiefly / primarily）。
- **統計**：每天完成幾張、目前記憶率、哪些字最容易忘、連續學習天數。
- 內建 51 個雅思 Writing Task 1 圖表題常用字，例如 soar、plummet、fluctuation、level off。

## 怎麼用

1. 打開網址，直接開始翻卡。按空白鍵翻面，按 1／2／3 評分；手機用點的就好。
2. 想加新單字：到「新增」頁輸入。要讓 AI 自動補資料，照頁面上的步驟申請免費的 Gemini 金鑰（約 3 分鐘）。
3. 想像 App 一樣使用：
   - **電腦（Chrome / Edge）**：網址列右邊的「安裝」圖示。
   - **Android**：Chrome 選單 →「加到主畫面」。
   - **iPhone**：Safari 分享按鈕 →「加入主畫面」。

## 隱私

- 學習進度、你新增的單字、API 金鑰，**都只存在你自己的瀏覽器**，不會上傳到這個網站或任何伺服器。
- 只有在你按「AI 產生資料」時，你輸入的單字才會送到你選的 AI 服務（Google Gemini 或 Anthropic Claude）。
- 換手機或清除瀏覽資料，進度就不會跟著走，建議偶爾到「設定 → 匯出 JSON」備份。
- 使用 Gemini / Claude API 需年滿 18 歲。
