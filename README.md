# Volcablearn

**用遺忘曲線背英文單字的閃卡網站。** 免費、免註冊，打開就能用。

👉 **立即使用：https://rjian-collab.github.io/Volcablearn/**

![Volcablearn 預覽](og-image.png)

## 可以做什麼

- **Google 帳號登入、跨裝置同步**：手機背到一半，換電腦登入同一個帳號就能接著背。不登入也能用。

- **依你的程度出題（CEFR A1～C2）**：第一次使用可以做 3 分鐘的分級測驗（認識／不認識，混入假字防亂猜），或自己選程度；之後每次答題都會自動微調，題目大多落在「剛好有點挑戰」的難度。
- **我的詞庫＋共有詞庫**：自己新增的字放在「我的詞庫」，同時送去 AI 審核，通過後加入大家共用的「共有詞庫」；別人加的好字也能一鍵收藏。測驗時可以選只考自己的、只考共有的，或全部。

- **閃卡**：看英文，翻面看中文、例句、同義字和搭配詞，自己按「不會／模糊／會」。
- **自動排複習**：依照遺忘曲線計算每個字什麼時候快忘了，在那天提醒你複習；越熟的字間隔越長。
- **新增自己的單字**：輸入單字，AI 幫你補上詞性、中文、例句、同義字和搭配詞，確認後加入閃卡（AI 需要自己的免費金鑰，沒有金鑰也能手動新增）。
- **一輪一輪的測驗**：每輪 5／10／20 題，有進度條；答錯的題目最後會再出一次，全部答對才算完成。每題有倒數計時（可選關閉／寬鬆／一般／挑戰），時間到算答錯，快答還有加分。題型有填字拼寫（附字母數提示）、選意思、同義字與詞性轉換、例句挖空、易混字辨析（例如 mainly / chiefly / primarily），也可以選「綜合」。
- **XP、等級和成就**：答對、翻卡都能拿 XP，連對有加分；設定每日目標、累積連續天數，解鎖「一週不間斷」「完美一輪」等成就徽章。
- **延伸詞彙一鍵加入題庫**：閃卡背面的同義字、派生詞、搭配詞旁邊有「＋」，按一下就變成新的閃卡。
- **統計**：每天完成幾張、目前記憶率、哪些字最容易忘、連續學習天數。
- 內建 51 個常用單字（多為描述趨勢、比較、數據的字，例如 soar、plummet、fluctuation、level off），也可以加入自己的字。

## 怎麼用

1. 打開網址，直接開始翻卡。按空白鍵翻面，按 1／2／3 評分；手機用點的就好。
2. 想加新單字：到「新增」頁輸入。要讓 AI 自動補資料，照頁面上的步驟申請免費的 Gemini 金鑰（約 3 分鐘）。
3. 想像 App 一樣使用：
   - **電腦（Chrome / Edge）**：網址列右邊的「安裝」圖示。
   - **Android**：Chrome 選單 →「加到主畫面」。
   - **iPhone**：Safari 分享按鈕 →「加入主畫面」。

## 隱私

- 不登入時，學習進度和 API 金鑰**只存在你自己的瀏覽器**。
- 用 Google 帳號登入後，學習進度會同步到網站伺服器（Cloudflare），讓你換裝置也能接著背；隨時可以在設定頁刪除雲端進度。詳見[隱私權政策](privacy.html)。
- 你新增的單字（只有單字內容，不含任何個人資料）會送到共有詞庫伺服器做 AI 審核，通過後公開給所有使用者。系統只用一組隨機產生的匿名代號來限制投稿次數。
- 只有在你按「AI 產生資料」時，你輸入的單字才會送到你選的 AI 服務（Google Gemini 或 Anthropic Claude）。
- 換手機或清除瀏覽資料，進度就不會跟著走，建議偶爾到「設定 → 匯出 JSON」備份。
- 使用 Gemini / Claude API 需年滿 18 歲。
