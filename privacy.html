Volcablearn 隱私權政策

最後更新：2026 年 10 月 25 日

Volcablearn 是一個免費的英文單字閃卡網站（rjian-collab.github.io/Volcablearn），由個人站長維護。這一頁說明網站會蒐集哪些資料、拿來做什麼，以及你可以怎麼刪除它們。

不登入時

  • 學習進度、你新增的單字、設定都只存在你自己的瀏覽器裡，不會上傳。
  • 你在「新增」頁投稿到共有詞庫的單字內容（英文、中文意思、例句等）會送到網站伺服器審核，通過後公開給所有使用者。投稿不會附上你的姓名或 Email，只會附上一組瀏覽器隨機產生的匿名代號，用來限制每天的投稿次數。
  • 你自己填的 AI API 金鑰只存在你的瀏覽器，不會送到網站伺服器。

用 Google 帳號登入時

資料用途
Google 帳號的使用者編號辨識你的帳號，讓不同裝置能讀到同一份進度
Email、顯示名稱在設定頁顯示你登入的是哪個帳號；判斷是否為站長
學習進度（每個字的複習紀錄、你的詞庫、XP、成就、設定）跨裝置同步

網站只向 Google 要求基本的登入資訊（openid、email、profile），不會讀取你的 Gmail、雲端硬碟或其他任何 Google 資料，也不會取得你的 Google 密碼。

資料存放與第三方服務

  • Cloudflare：網站伺服器與資料庫（Cloudflare Workers、D1）存放共有詞庫、登入狀態與同步的學習進度。
  • Cloudflare Workers AI／Google Gemini：投稿到共有詞庫的單字內容會送到 AI 做內容審核（優先用 Cloudflare 的 AI，無法使用時改用 Google Gemini）。
  • Google：提供「用 Google 登入」。
  • GitHub Pages：提供網頁本身。

匿名使用統計

為了知道有多少人在用這個網站，網站會在你的瀏覽器裡產生一組隨機的匿名編號（不含姓名、Email 或 IP），每天第一次打開網站時把這組編號送到伺服器，用來計算「每天有幾個人上站」。你新增單字時，也會記錄「這組編號新增了哪個英文單字」，用來統計大家常加哪些字。

這些統計只有站長看得到，不會用來辨認你是誰，也不使用 Google Analytics 等第三方追蹤服務。清除瀏覽器的網站資料就會換成新的編號。

網站不放廣告，也不會把你的資料賣給或分享給其他人。伺服器為了限制濫用，會把連線 IP 經過雜湊處理後計算每日使用次數，不會保存原始 IP。

保存期間與刪除

  • 登入狀態在 60 天沒有使用後失效。
  • 你可以隨時在網站「設定 → 帳號與跨裝置同步」按「刪除雲端進度」，伺服器上你的學習進度與登入紀錄會立即刪除（這台裝置上的進度仍保留）。
  • 已經公開到共有詞庫的單字屬於公共內容，不會跟著帳號刪除；如需移除，請聯絡站長。
  • 清除瀏覽器的網站資料，就會刪除存在瀏覽器裡的進度。

未成年使用者

使用 Google 帳號登入須符合 Google 對帳號使用者的年齡規定。若你未滿 18 歲，建議在家長或監護人知情的情況下使用登入同步功能。

聯絡我們

對隱私權有任何問題，或想刪除共有詞庫中的內容，請到 GitHub Issues 留言。
